How it works

One shortcut. One PNG. Nothing else.

YT Capture Pro works entirely through standard browser APIs. It captures what is already rendered on screen — exactly like pressing PrintScreen, but smarter.

Step 01

User presses Alt+S on any YouTube video

The keyboard shortcut triggers the content script already running on the YouTube tab. No new network requests are made at this point.

Step 02

drawImage() copies the visible video frame

The <video> element already rendered in the browser is drawn onto an off-screen HTML5 Canvas. No stream data is accessed.

Step 03

Canvas exports to PNG and saves locally

canvas.toDataURL('image/png') creates the image. Chrome's downloads API saves it to the user's device. The image never leaves the user's computer.

// The entire capture mechanism — standard browser APIs only const video = document.querySelector('video'); // already in the DOM const canvas = document.createElement('canvas'); const ctx = canvas.getContext('2d'); canvas.width = video.videoWidth; // native video resolution canvas.height = video.videoHeight; ctx.drawImage(video, 0, 0); // copies the rendered frame const dataUrl = canvas.toDataURL('image/png'); // PNG only — no video/audio chrome.downloads.download({ url: dataUrl, filename: 'screenshot.png' });

No YouTube API calls. No CDN requests. No stream access. The extension reads only what the browser has already downloaded and rendered to the screen. It is functionally identical to a user taking a screenshot with their operating system's built-in tool — but with smart metadata and optional enhancements.

Technical transparency

Every question answered honestly.

We know tools that interact with YouTube content face scrutiny. Here is exactly what this extension does and does not do.

✓  What the extension DOES

  • Reads the already-rendered <video> element in the DOM using drawImage()
  • Exports that frame as a PNG using the standard Canvas API
  • Saves the PNG to the user's local downloads folder
  • Reads subtitle text from YouTube's DOM (.ytp-caption-segment elements)
  • Stores user preferences in chrome.storage.sync (local)
  • Sends license key + anonymous device UUID to our server for Pro validation
  • Uploads screenshots to Notion via the user's own Notion API key (optional)

✗  What the extension NEVER DOES

  • Access YouTube video stream URLs, CDN endpoints, or blob:// URLs
  • Download video or audio data in any format
  • Use any unofficial YouTube API or private endpoint
  • Work if the video element is not visible or loaded
  • Bypass Widevine DRM — DRM-protected content returns a black canvas (browser-enforced)
  • Collect browsing history, viewing history, or personal data
  • Send screenshots to any server — they stay on the user's device
  • Execute remote JavaScript — all code is shipped inside the extension package

🔒  DRM content behaviour

When a user attempts to capture a DRM-protected video (YouTube Premium movies, licensed sports content), the HTML5 Canvas API returns a solid black rectangle. This is enforced at the browser level by Widevine DRM — our extension cannot see or access those pixels. We do not attempt to bypass this behaviour.

📡  Network requests made

  • ytcp-license-server.vercel.app — license key validation (Pro users only)
  • api.notion.com — screenshot upload (only when user has configured Notion and triggers sync)
  • fonts.googleapis.com — popup UI fonts (standard web font)
  • No YouTube API calls, no analytics, no tracking

Privacy

Your data stays yours.

YT Capture Pro does not collect browsing history, YouTube viewing history, or personal information. Screenshots are saved locally to your device and never sent to our servers.

Pro license validation sends only your license key and an anonymous device UUID (a random identifier generated locally) to our server. This is used solely to verify your purchase and enforce the 3-device limit.

Notion integration is entirely opt-in and uses your own Notion API key, which is stored only in your browser's local extension storage — we never receive or transmit your Notion credentials.
